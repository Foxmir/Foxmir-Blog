RL读图：稳定=收敛=最优？

发布于

2026年11月20日

引子

在模型训练过程中： 1. 如果变量数值稳定了，这一定是好消息吗？ 2. 曲线稳了，算收敛吗？ 3. 如果它收敛了，我能说它是最优吗？ 4. 如果它是最优了，它一定表现好吗？

  1. 我的回报中间波动很剧烈，但最终表现接近满分，我能说是全局最优吗？
  2. 如果梯度范数长期接近0，那我处在局部最优/全局最优吗？
  3. 性能不再增加，这是达到了全局最优还是卡在局部最优？
  4. 好不容易出现高分回报，要不要把训练赶紧停下来？万一又掉下来不就傻眼了？

在强化学习的训练当中，你经常看到一种现象，甚至可能你自己也会这样做。直接把某张图在群里面抛出来，然后就问，这个收敛了吗？而且这个图每个人发的也不同，有的人发的是训练结果，有的人发的是评估结果，有的人发的是损失函数，各种各样的。

随机性是强化学习的一大特点，所以你会觉得诊断比较困难。同时，下结论的时候，说某个指标现在是什么状态，也容易说得不太硬气。

而且，在理论上，工程上，和平时交流中，即便大家在用同一个概念，也可能在表达不同的意思。

所以我准备了这个视频。让我们来聊聊这些很少会有人讲到的真实工程摩擦该如何理解和处理。

我会在每个页面直接把结论放出来，并附加简单的解释。

毫无疑问，稳定，收敛，最优性，以及表现好坏，这四个概念肯定不一致。但什么情况下这些概念才成立？如果其中某个概念成立了，那么此时其他概念能成立吗？以及为什么。

1. 概念的讨论对象

  • 模型参数？训练指标？评估结果？→ 图表上的变量
  • 目标：（输入）最优参数 → （输出）最佳表现
  1. 稳定&收敛：任何变量都适用，与它是什么变量无关
  2. 最优性&表现好坏：模型参数 & 评估表现
  3. 其他变量一般不讨论最优性
  4. 表现好坏取决于评估表现，而非训练表现

稳定和收敛这两个词本质上是在讨论对象自身的变化，不管你关心哪个变量，无论是模型参数，还是训练指标，评估结果，你都可以谈它们是否稳定，是否收敛。

但最优性和表现好坏，一般是针对于你的目标变量来讨论。 我们的目标通常是要达到某个标准下最棒的表现效果。最棒的表现效果对应最棒的模型参数。表现达到最优，参数就必然最优，反过来也一样。两者相互对应。但严格来说，这里的表现是指期望回报，现实中我们肯定拿不到，我们会用评估表现，来近似估计期望回报。

留意，这里用的是评估结果，而不是训练结果，来衡量模型表现的。这和在监督学习当中，用测试集而不是用训练集来衡量模型表现是同样的道理。

2.1 动态特性：稳定&收敛 | 概念&关系

  1. 概念——是否趋向固定值

  2. 稳定：特定观察窗口和尺度下，波动幅度保持足够小

  3. 收敛：长期，趋向一个固定值，波动幅度持续趋向于 0

  4. 关系：

  5. 稳定可以是短期/长期状态，收敛必然指最终状态：稳定依赖于特定的观察窗口和尺度，但收敛不依赖。这意味着，即便你中间大幅夸张波动/非单调，你只要长期来看，越来越趋向某个固定值，也可以被认为是收敛。

  6. 收敛了一定稳定，稳定了不一定收敛：

    1. 举例：比如最终结果在9.99到10.01之间波动，但始终不趋向任何固定值。
    2. 解读：
      1. 稳定了但没收敛：波动足够小但不可忽略，0.02
      2. 工程上属于近似收敛：如果0.02的波动可忽略的话

区分稳定和收敛的关键在于，看这个变量是否趋向于某个固定值。这个固定值可以是你事先预设好的，也可以事先完全不知道。

如果某个变量达成了收敛，就说明，它长期无限逼近某个固定值，且波动幅度持续缩小接近于0。 因此，它无论你后面还有多长时间，无论你这个图的尺寸是放大还是缩小，都成立。

收敛指向的是最终状态的表现，所以，你是如何到达收敛状态的，都不推翻最终的收敛状态。至于这个中间过程，你是很平稳地到达，还是波动很大地，很辛苦地到达，都没有关系。只要你满足变量最终收敛到某个固定值，就可以了。你就可以理直气壮地宣称，它收敛了。

如果该变量没有趋向于某个固定值，伴随有小幅度的波动，足够小，但不足够被忽略，这个时候你不能宣称它收敛了，但可以宣称它稳定了。

而且这个稳定和你的观察窗口，以及观察尺寸明确相关。

从稳定这一刻起，你后面如果继续训练，可能仍然是稳定的，也可能是不稳定的。而且整个过程，可能是方差逐渐变小后到达的，也可能是方差波动始终很大，最后莫名其妙到达的。

同时，如果你把你的图表进行缩放，当然会感受到波动幅度的变化。虽然缩放并不改变数值本身，但会改变视觉效果。因此，尽管它在数值上是稳定的，也可能看起来非常不稳定。

所以我们一般会针对某个已经呈现好的图，看它的数值是不是变化足够小，然后宣称它整体，或者中间某一阶段，是稳定的。

那么，你现在就能很自然地推导出两者的关系。收敛了一定稳定，稳定了不一定收敛。这个不要背口诀啊，否则太绕了。理解啥是稳定，啥是收敛，这个关系自然而然就出来了。

举一个比较典型的曲线变化作为例子，某变量历经波折最终缩小到9.99和10.01之间，但没进一步收缩。最终的变化幅度是0.02，这个幅度足够小，所以我们可以声称它最终稳定了。同时，假设现实意义上，这个变化幅度完全可以忽略，我们甚至能直接声称它近似收敛了，且固定值10。

2.2 动态特性：稳定&收敛 | 实际应用

  1. 没有经过数学证明，在工程上，我们也可以声称变量已经“近似收敛”：
  2. 只观察到变量基本稳定并带有微小波动时，如果我们认为暴露的窗口周期已经足够长 + 波动已经不具备意义，可以忽略，那么，就可以声称该变量已经“近似收敛”。
  3. 反之：
  4. 如果已经稳定，但观察的窗口周期不够长，这是暂时稳定，且最终是否收敛未知
  5. 如果已经稳定在某个值附近，但其波动的误差范围虽然小，但在意义上不可忽略：目前稳定，而非收敛，最终是否收敛未知

借着这个例子我们来总结下，当变量曲线差不多稳定了，你什么时候有资格宣称它达成收敛？

毫无疑问，严格意义上的收敛是数学证明的领域。我们在这一节谈论的是“工程上的近似收敛”

它必须要满足两个条件：一，“暴露的窗口周期已经足够长”，二，“剩下的波动不具备现实意义”。缺少任何一个条件都不行。这些都是很好理解的。

只不过，在现实中，大家的描述会更粗糙一些，通常会混讲“稳定”，“收敛”，“近似收敛”。只要它不影响彼此的逻辑交流，那么也就这样，这很好。但是在你需要严肃表达的情景中就需要明确区分了。

我们顺便简单提及下，为什么当你看到损失函数的曲线都趋近于稳定，甚至趋近于0的时候，相较于监督学习而言，你对强化学习的稳定性更加难以信任，你会更害怕，再多训练一段时间，变数可能会增多。

这是因为，在强化学习当中，采集到的数据分布会改变当前策略，策略改变又影响了下一次的数据采集，两者相互依赖，这使得训练的不稳定性更强。即便你现在看到某个窗口下某个变量表现稳定了，随着训练继续发生，数据和策略的相互依赖可能会放大波动，也可能相互抑制，所以结果难以预测。

3.1 最优性：局部最优&全局最优 | 潜在预设

  • 最优性&表现好坏：模型参数 & 评估表现
    1. 其他变量一般不讨论最优性
    2. 表现好坏取决于评估表现，而非训练表现
    3. 最优参数可以有多个
  • 概念&关系 → 如何判断当前解的最优性？ → 实际应用

这一点，我们在视频开头讲过，这里我们再次强调。当我们谈及“最优性”的时候，往往是在谈论模型参数这个独特变量。最棒的模型表现，必然对应最棒的模型参数。

但最棒，不等于唯一。最棒的模型参数可以有多组。只要都能带来最棒表现，就都具有最优性。

我们会从它们的概念和关系入手，并谈到确定最优性的手段，最后落点到实际应用当中。

3.2 最优性：局部最优&全局最优 | 概念&关系

  1. 概念——关键看范围

  2. 局部最优：附近没有更好的可行解，但较远处可以有

  3. 全局最优：整个允许的解空间里，都没有更好的解

  4. 关系：全局最优一定也是局部最优；局部最优未必是全局最优

概念本身就非常直白。

“最优性”是一个“比较”概念。意味着我比别的模型参数更优秀。 两个概念中，一个强调局部，一个强调全局，对应的是“优秀”发生的作用范围。

那么关系就非常简单了。全球第一肯定是全国第一，全国第一未必是全球第一。

3.3.1 最优性：局部最优&全局最优 | 如何判断当前解的最优性？

  1. 存在性：数学上，有没有全局最优解？
  2. 可求解性：模型和算法上，这些手段能否找到/逼近数学上的最优解？
  3. 当前解的最优性判定：工程上，我们手头的解，是否是最优解？/ 距离最优解有多远？⛳
  4. 穷举比较
  5. 结构性最优判断：利用目标的数学性质认证当前解。
    1. 例如：无约束，可微，凸函数，优化时，发现当前点的梯度为0，即为全局最优解
  6. 逼近目标界限：目标是否存在上下界，或者保证目标产生上下界的结构。

进一步，想要确定最优性的话，这里会有三个不同层次的问题混在一起，我们必须先分开。

因为我们的目标在于会读图，会诊断。所以我们更关心第三个问题。至于理论上有没有最优解，模型的表达力是否充分，算法上能否逼近，这些都不在我们的讨论范围内。它们之间的依赖关系我们也先略过。

我们就想知道，我千辛万苦训练出来的这个参数，它是不是最优解，或者近似最优解。

这里有三种手段。名字有点抽象，但非常好理解。

第一，直接穷举比较，暴力求解。当然，它不现实。

第二，利用优化问题的数学性质来判定最优性。我们给一个最小化损失函数的经典例子。在无约束条件下最小化一个可微凸函数时，如果算出来当前损失函数的梯度等于0，就说明你到达了整个凸函数的最低点，那么当前参数自然就是全局最优解。

但留意，不是所有的损失函数都满足这一点，也不是只要梯度为0就是全局最优解。 我们刚刚给的是一个无约束，可微，凸函数的特例。 如果有约束时，要检查这个点是否满足约束。如果满足，可微凸函数在这里的梯度为零的时候那就是全局最优；如果不满足，相当于这个解被排除在外了，它自然就不是最优解。 又或者你是最优点不可求导，那么你自然也不能通过算梯度来判断最优性。 甚至你的目标函数是非凸函数，那么梯度为零的点，也未必是全局最优解。

所以总结来看，想用这一条判定，前提是你的“优化目标本身”必须具备这类特殊的数学结构。但是在深度神经网络，比如深度强化学习当中，优化目标的结构通常高度复杂，不具备这种单纯凸函数或者凹函数的优良特性，所以这条最优性的判据也用不到。

第三，就是逼近目标的界限。这条判据你可能会经常用到，我们需要详细说一下。

这里的关键词有两个，一个是目标，一个是界限。而且必须是“目标“的”界限”。

3.3.2 最优性：局部最优&全局最优 | 如何判断当前解的最优性？

  • 逼近目标界限：以最大化期望回报为目标时，最大化回报达到最大即最优： 1. 我们通常以评估表现来近似估计期望回报 2. 当评估表现逼近目标极限最佳，可以被认为达成了”近似全局最优” 3. 例如：默认500步限制下的cartpole-v1的游戏的单回合最高分500分。如果评估回报是495分，而5分的差距被认为足够小/可以忽略，可认为性能近似全局最优 4. 留意：并非所有的RL环境里的回报都有边界，就算有，环境也未必支持我们拿到，这种情况无法通过该手段判断最优性。

  • 必须明确谁是目标？

    • 监督学习中，以”最小化（评估/测试集中的）损失函数“为目标，通过追求到达损失函数的界限来追求参数最优性
    • 强化学习中，目标是“期望回报”。而非损失函数，或，梯度范数。（少数特殊情况下，如果损失函数是期望回报的负数， \(L(\theta)=-J(\theta)\) ，则可以将其用于判断最优性）

在RL中，我们通常是以最大化期望回报为目标。那么，如果已经知道这个目标不可能越过某个界限，当我们达到这个界限，就说明到达了全局最优，没有其他解比当前解更好。如果足够接近该界限，则说明到达了近似全局最优，可剩的改善空间已经足够小。

真正的期望回报是拿不到的，属于理论概念。现实中我们会用评估表现来近似期望回报。

在 Cartpole 这样的游戏中，单回合最高分500分，不管你中间的训练表现如何，充分评估下回报拿到了500分，你就是全局最优。拿到近似500分，你就是近似全局最优。

我甚至可以给一个极端例子。假设同一个游戏，条件都不变，但我现在人为规定，单回合最多得2分，而我的训练目标是拿到满分，满分就是2分。那么可想而知，你随便训练一下，都能拿到2分。那么你每次都可以说自己的参数是全局最优。

但并非所有的RL环境里的回报都有边界，就算有，环境随机性也未必支持我们真的到达。所以，你的期望回报得有一个明确的边界，同时，你的算法或环境支持你到达或逼近，你才能采用这个手段来判断最优性。

在监督学习当中，我们还可以以”最小化评估或者测试集上的损失函数为目标“。比如MSE，也就是均方误差损失函数，它的理论下界是0，如果你到达了它的理论下界，你的参数就必然是全局最优。

我们刚才强调过，我们关心的是”目标“的”界限“。那么“非目标”的对象达到自身的边界值，对于我们判断最优性往往是没有帮助的。比如说，在强化学习算法中，虽然我们的目标是期望回报，但我们也同样会采集损失函数和梯度范数，其中，梯度范数的理论下界就是0，而且部分损失函数，比如MSE，也有理论下界 0。

强化学习中，损失函数通常是用在算法不同的阶段，不同的逻辑链上，充当一个拟合局部样本的中间工具，而且它往往是反映“训练过程”中，单个批次的损失函数值。 最小化训练阶段的单个批次的损失函数值，和我们的目标，即最大化评估阶段中期望回报，两者的数学关系不是协同对应的。

梯度范数到达边界0，确实可能是一个全局或局部的最优点，但也可能是鞍点或平原。所以它到达边界，损失函数不一定到达边界，期望回报也未必最优。

但当然，梯度到达 0 也是有价值的。我们在上文讲过，当“优化目标本身”具备特定的数学结构，比如上文提到的无约束可微凸函数时，它的梯度为 0 就能直接代表拿到了全局最优解。

现在，我们再次回归到核心结论：强化学习中，通常以最大化期望回报为目标，且当回报达到最大即达成全局最优。非目标对象，没有这种待遇。

再来聚焦一下我们关心的问题：如何判断当前解的最优性？我们也提到了三种手段，分别是，第一，暴力穷举；第二， 利用目标的数学性质进行结构性最优判断；第三，就是刚刚提到的，逼近目标的界限。

最后，当这些证据都不充分时，第一第二第三都不满足，我们也不能直接否认说当前不是最优解，我们就只能说，目前无法确定。

3.4 最优性：局部最优&全局最优 | 实际应用

  1. 常见的沟通场景：模型表现看起来像是训练被卡住/表现停滞了 —— 局部最优假设
  2. 实际的目标需求：追求足够好，以足够好作为可接受的结果/停止标准

在实际应用中，你会经常听到别人对着一个训练表现停滞的图解释说，“这可能卡在了局部最优，导致模型不能改善，参数跳不出来了”之类的话。那么对方这样表达的时候，实际是什么意思呢？

首先，现象很明确，模型处在局部最优的推断也确实有可能，但证据不足。

曲线表现停滞表明当前参数的训练效果没有进一步改善，不代表，当前参数附近没有更好的参数。完全有可能在邻域范围，也就是旁边儿，确实有更棒的参数组合，但如果我们现在在鞍点或平原，导致每次参数更新几乎没变化，同样也可以表现停滞。

训练曲线仅仅提供了关于它自身路径的参数信息，我们并没有关于周围参数空间足够的信息，所以这种表达一般只是一种简便的机制推测。

实际工程中，即便不知道机制，也可以进行推测诊断，就是大体猜一猜，定几个最可能的方向，然后做实验性的修改，再跑一跑看看。我们也确实希望训练可以一遍又一遍拿到更好的结果。但是最优性，不是训练结果是否可接受的一个必要条件。

我们在实际工程中，一般是追求一个足够好，而非最优的结果。当然，你这个足够好的结果可以同时是最优的，这个我管不了。

那什么是“足够好”呢？简单说就是你满意就行。在你所能供应的资源条件下，达到了你的既定标准，这就足够好，可以停止训练了。即便这里存在比你定的标准还要表现更好的参数，这也不重要，因为这就属于另外一个项目了。

4.1 三组概念：稳定收敛，最优性，表现好坏 | 概念本质

  • 本质上它们在关心三个不同的问题：
    1. 稳定和收敛：变量随时间的变化趋势 —— 变化如何？
      • 收敛了一定稳定，稳定了不一定收敛
    2. 最优性：不同解之间的可比性 —— 是否最好？
      • 全局最优一定也是局部最优；局部最优未必是全局最优
    3. 表现好坏：期望回报是否达到人为设定的标准 —— 是否达标？

我们现在知道的概念越来越多了，我们在这里把概念两两一组放在一起，一共三组。那么，各组概念之间可以互推吗？如果我成立，你一定成立吗？这一节会非常实用。

“表现好坏”这个概念上文虽然没有单独解释，但值得一起放进来。这个就是纯字面意思。在我们给定的场景中，给定的标准下，达到标准或者接近标准就是好表现，反之，就是坏表现。

这三组概念在关心三个不同的问题。

稳定和收敛是在关心变量随时间的变化趋势。 最优性关心不同解之间的可比性。 表现好坏关心期望回报是否达到了人为设定的标准。

当你想要知道概念之间的依赖关系的时候，实际上就是根据你手头的信息看看能否回答相应的问题。我们直接从一些常见的直觉错误入手来推导下。

4.2 三组概念：稳定收敛，最优性，表现好坏 | 错误直觉

  1. ❌ 稳定了 / 收敛了，最优了，一定是好表现
  2. ❌ 稳定了，收敛了，训练停滞了，一定至少是局部最优
  3. ❌ 表现是全局最优，没有学习空间了，继续训练能保持最优表现

最常见的直觉错误就是当你听到别人报告自己的训练结果稳定了，收敛了，甚至对方说自己已经达到了局部最优，或者是全局最优，这不一定代表好消息，它的训练可能远远没有结束。这里没有信息来回应是否达到了设定标准，所以它不一定是好表现。

如果模型的表达力不够，那么即便我们到达了模型的能力极限，这个解可能依然很烂。

第二种常见的直觉误解，我们在上文讲最优性的应用时提到过，局部最优是这种稳定或停滞现象的一种可能机制，但不是唯一机制。

现在我们换个角度再论述下。训练持续的时间很久，使得你能够回答“训练回报如何随时间变化”这个问题，但它并没有把当前参数和周围空间的其他参数进行过比对，所以你无法回答“当前参数是不是周围空间里最好的”。所以第二句话也不对。

那么假设你真的到达了全局最优，你找到了解空间中最棒的解，已经没有任何提升空间了，继续训练的话模型表现是不是依然可以很好？

全局最优回答了当前解空间中谁最好的问题，但在后续的训练中能否保持，取决于随着时间变化，与它相关的其他因素如何改变？比如环境信息，样本分布，采样误差，噪音大小等等，这些信息是缺乏的。后续训练本身并不自动提供结果保证，期望回报可能依然是全局最优，也可能表现下降。所以这句话当然也不对。

5.1 引言回顾 | 问题

在模型训练过程中： 1. 如果变量数值稳定了，这一定是好消息吗？ 2. 曲线稳了，算收敛吗？ 3. 如果它收敛了，我能说它是最优吗？ 4. 如果它是最优了，它一定表现好吗？

  1. 我的回报中间波动很剧烈，但最终表现接近满分，我能说是全局最优吗？
  2. 如果梯度范数长期接近0，那我处在局部最优/全局最优吗？
  3. 性能不再增加，这是达到了全局最优还是卡在局部最优？
  4. 好不容易出现高分回报，要不要把训练赶紧停下来？万一又掉下来不就傻眼了？

到这里，正文就完全结束了。出于乐趣，我们来看下之前引言部分的问题。你现在应该会觉得很清晰，很好判断。

5.2 引言回顾 | 问题 & 答案1/2

  1. 如果变量数值稳定了，这一定是好消息吗？ —— 不一定，也可能稳定烂表现

  2. 曲线稳了，算收敛吗？ —— 不一定，要看是否收敛到固定值 / 波动小到忽略

  3. 如果它收敛了，我能说它是最优吗？—— 不一定，它随时间不再变化，不代表周围没有比它更好的其他解

  4. 如果它是最优了，它一定表现好吗？ —— 不一定，可能是个烂模型，烂模型最高分，也可能是烂表现

  5. 我的回报中间波动很剧烈，但最终表现接近满分，我能说是全局最优吗？ —— 可以，但准确讲是近似全局最优。它目前是最棒的解，和中间过程没有关系。

  6. 如果梯度范数长期接近0，那我处在局部最优/全局最优吗？—— 不一定。对于非凸函数来说，梯度为0可能只是处在鞍点/平原，甚至算不上局部最优。就算真的处在了局部最优，我们并不知道更远处的地形的信息，无法推断全局最优性。但如果是无约束的可微凸损失函数，那么梯度为0时就能认证损失的全局最优了

  7. 性能不再增加，这是达到了全局最优还是卡在局部最优？—— 当然都不一定是。只是表现停滞了，不代表你的解比周围的解更好。

5.3 引言回顾 | 问题 & 答案2/2

  1. 好不容易出现高分回报，要不要把训练赶紧停下来？万一又掉下来不就傻眼了？
  2. 只要目标达成，就有资格停止训练。关键不是看曲线是否漂亮/稳定，而是你的目标是否满足。（但目标设定是否合理，是另外一回事）
  3. 如果你不只是关心单次高分，你期待训练得到更多次数的高分，更稳定的高分，你的目标本身应该包含诸如平均回合回报，高分比例，标准差/方差这类指标要求在内。具体看需求。
  4. 无论你的目标是什么，继续训练都可能导致性能进一步下降，但这不一定对当前目标构成威胁。
    1. 如果你不希望模型参数在后续训练中被改坏，则立即保存参数即可，后续训练中随时可以回到当前的参数版本。
    2. 固定当前模型及其使用方式，如果环境和评估条件也保持不变，那么期望回报自然也保持不变（单次评估结果仍可能波动）
    3. 如果你仅仅保证使用当前版本的模型参数，但环境或者评估标准一直在变化，并希望它仍然能维持好表现，这难以做到。如果你有这种稳定需求，可以在一开始就追求一个多环境，多条件下的鲁棒性目标。
